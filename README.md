# Telegram Business NFT offer bot

## Запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Скопируйте `.env.example` в `.env` и задайте `BOT_TOKEN` и `ADMIN_IDS`.
3. Запустите: `python bot.py`

## Команды в Telegram Business-чате
Все команды требуют URL и сумму, например `.3ofer https://t.me/nft/InstantRamen-142855 500`.

- `.1ofer t.me/nft/Slug-123 500` — превью, если страница отдаёт доступное изображение; название-ссылка.
- `.2ofer https://t.me/nft/Slug-123 500` — текст, без NFT-медиа и без превью ссылки.
- `.3ofer https://t.me/nft/Slug-123 500` — форматированный текст, название-ссылка и изображение, если его удалось скачать.
- `.4ofer https://t.me/nft/Slug-123 500` — текст без форматирования и без медиа.
- `.5ofer https://t.me/nft/Slug-123 500` — изображение, если доступно, плюс простой текст.
- `.6ofer https://t.me/nft/Slug-123 500` — форматированный текст с кликабельной ссылкой, без NFT-медиа.
- `.7ofer https://t.me/nft/Slug-123 500` — форматированная карточка с изображением, если доступно.
- `.8ofer https://t.me/nft/Slug-123 500` — простой текст со ссылкой в тексте, без NFT-медиа.
- `.9ofer https://t.me/nft/Slug-123 500` — условия предложения и ссылка, изображение, если доступно.
- `.10ofer https://t.me/nft/Slug-123 500` — компактный формат, изображение, если доступно.

Изменение в обработке изображений: бот сначала скачивает превью сам и передаёт Telegram загруженный файл, вместо того чтобы просить Telegram скачать удалённый URL. Если изображение недоступно, бот отправляет текстовый вариант, а не падает на `failed to get HTTP URL content`.

## Ограничения
Это обычные сообщения бота с inline-кнопками. Кнопки записывают выбор и уведомляют администратора; они не являются системными кнопками Telegram «Принять/Отклонить», не совершают передачу NFT и не переводят Stars. Полноценный системный офер из интерфейса Telegram нельзя гарантировать этим способом.
